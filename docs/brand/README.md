# Brand Assets

## README Cover

[worldweft-cover.png](../worldweft-cover.png) is the project's illustrated cover.
It was generated with the built-in ImageGen tool on 2026-11-13, then copied
into this repository without pixel edits. The image is 2172 × 724 pixels.

The cover uses a miniature landscape woven from fabric and thread to connect
the project's name with persistent, inhabited worlds. It is brand artwork;
the in-game development recording is presented separately in the README.

The two lines of image copy are:

- Worldweft
- Worlds that live on their own.

## Architecture Figure

[architecture.svg](../architecture.svg) is an editable SVG, kept separate from
the cover so technical labels and the four-stage runtime contract remain exact.
Its text description and the detailed architecture guide provide the same
information without relying on an image.
